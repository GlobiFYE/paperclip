# Decisiones de arquitectura (ADR)

Esta carpeta guarda las decisiones de arquitectura propias de este fork
(`traduccion-es` y lo que venga después). Un ADR por archivo, numerado y
correlativo: `NNNN-slug.md`.

No existía carpeta de ADRs en el repo cuando se creó esta. `doc/architecture/`
guarda documentos de diseño de upstream; `doc/plans/` guarda planes fechados
(ver `AGENTS.md`, regla 5). Las decisiones de este fork van acá para que queden
separadas de lo que mantiene upstream y no compitan con sus archivos.

Los ADR de este fork están en español: son para el equipo de Chanchu Labs y no
se contribuyen a upstream.
