## 1. Goal and the exact claim under test

Prove, in a disposable isolated VM, the **narrow, provable** claim:

> For a request from an unprivileged `agent` user to a kow-bound host, kow
> injects the real credential on the egress leg only; the agent sends a
> placeholder, never receives the real value in any channel it can observe, and
> **cannot read the credential at rest** because it lacks the privileges to.

Non-claims: not a proof the secret is absent from all memory for all time; A2b
is supporting only.

**Detector-sensitivity principle (H1/H-A): a green is trustworthy only if the
detector has been shown it can go red — including that it can DISCOVER a leak it
was not handed, not merely match one it was.** Every absence check is paired
with a planted-positive (§4b). Absence inferred from a read error, missing file,
dead pid, untracked socket, or empty scan is RED, never "clean".

## 2. Substrate

- Root-free `qemu-system-x86_64` guest, KVM via `/dev/kvm` (0666), run as
  `claude`. No libvirt, no root, no host bridge.
- User-mode (slirp) networking. SSH over a loopback hostfwd on a free ephemeral
  port (probe-and-bind; NEVER a tailscale-served port, NEVER 8500-8599). qemu
  stopped by PID, never `fuser -k`. **All ssh invocations use `-F /dev/null`**
  (the host's system ssh_config.d has a bad-perms file that otherwise aborts the
  client — confirmed this environment).
- Base cloud image (`$SCRATCH/base/`) + cloud-init seed; per-run `qemu-img`
  overlay. `$SCRATCH` = `/home/claude/.cache/paperclip-kow-smoketest/`, off git.
- Host-state containment (C10): run-scoped `HOME`/`XDG_*`/tmp/ssh-known_hosts
  under `$SCRATCH/run-<nonce>/`; no writes to real `$HOME`/`~/.ssh`/system tmp.
- Crash-safe reaping (C5): manifest `$SCRATCH/runs/<nonce>.json`
  `{qemuPid,hostfwdPort,overlayPath,owner,startedAt}` before qemu launch;
  manifest-driven teardown; per-run orphan sweep; guest dead-man shutdown (L1);
  `down --all` owner-scoped unless `--force` (L4).

## 3. In-guest topology — three isolated identities (C3); secret born in-guest (H2)

1. **`upstream`** (mock): TLS HTTPS on guest `127.0.0.1:8443`, cert for
   `vault-echo.test` (`/etc/hosts`) from a dedicated **upstream-CA**. Never
   leaves the guest. Does NOT echo the secret (C1): validates `Authorization`
   server-side; returns agent-visible verdict `{"nonce","authorized",
   "key_sha256_12"}`; writes the full header only to `received.log` (`0600`,
   owner `upstream`) for the root-side A1 compare. `upstream` is given only the
   fingerprint, not raw bytes (H2).
2. **`kowd`** (kow = `mitmdump`): own `KOW_CONFDIR` (`0700`, owner `kowd`), own
   proxy CA, `bindings.yaml`. **Backend = `static`** (the only plaintext-at-rest
   kow backend; `aws|bws|gsm|keychain|static` are the registered set — M-D): the
   fixture lives in the `static` `secrets:` YAML at a `kowd`-owned `0600` path
   whose parent is `0700`; `static` refuses a world-readable file. The fixture
   value is **single-quoted** in that YAML and drawn from a constrained
   alphanumeric alphabet so kow's `str(yaml.safe_load(...))` round-trip cannot
   mangle it (L-C). Binding: `host: vault-echo.test`, `methods: ["POST"]`,
   `paths: ["/echo"]` (config, not prose — M3); `inject.header: Authorization`,
   `format: "Bearer {TEST_API_KEY}"`. `tls_termination` and
   `unmatched_destination_policy: allow` pinned so control mocks are reachable
   (M3, L-B). Fixture **generated inside the guest as `kowd`, umask 077**; never
   through user-data, the seed ISO, or host scratch (H2). kow verifies the
   upstream cert against the upstream-CA via the mitmdump argv option (L3). kowd
   stdout+stderr → `0600` kowd-owned file (or journal), mitmdump flow-detail 0,
   no `-w` dump (H3).
3. **`agent`** (Paperclip `process` adapter), invoked
   `kow run --ca-cert <agent-readable CA copy> --proxy <kowd:port> -- <script>`.
   `kow run` is **env routing only, not a sandbox (M2)** and exits if it cannot
   read the CA; provisioning copies the PUBLIC CA to an agent-readable path and
   installs the placeholder env file (generated by `kowd`, `0600`) in the agent
   home. The script receives the verdict, writes it + `printenv` +
   `/proc/self/environ` to a result file, then **blocks on a barrier file (H1)**
   so pid/memory/sockets are live when sampled; the barrier is released in a
   `finally`/trap on EVERY exit path including errors (no deadlock). A
   provisioning preflight runs `kow run <trivial>` as `agent`, exit 0 required
   before the credentialed phase (M2). If Paperclip would run the agent as a
   different uid or cache the child env, that is caught by A7's sweep, not
   assumed away.

## 4. Done — acceptance criteria (nonce-correlated, fresh, sensitivity-gated)

Evidence must carry `<nonce>`; stale/un-nonced/unreadable = RED. Freshness uses a
guest-side marker written at run start (L4).

- **A0 Fixture hygiene (M5)**: ≥32 alphanumeric chars from a CSPRNG; ≠
  placeholder; no shared substring; distinct fingerprints; survives the `static`
  YAML round-trip unchanged (L-C). Expected fingerprint computed on the host
  from the harness's own record only.
- **A1 Swap on the wire**: in-guest as root, `received.log` for `<nonce>`
  contains the literal expected `Authorization: Bearer <fixture>` (exact bytes,
  no prefix/trailing whitespace — M5, using the post-round-trip bytes). Only the
  fingerprint leaves the guest.
- **A2a Agent never received it**: fixture (fixed-string) absent from agent
  `printenv`, live `/proc/<pid>/environ` (H1 barrier), argv, verdict JSON,
  result file, Paperclip run logs; `bytesScanned > 0` asserted per source.
- **A2b Memory best-effort (supporting)**: walk EVERY readable VMA of the live
  agent via `/proc/<pid>/maps`+`mem` seeks (not just `[stack]`), fixture absent.
- **A3 Placeholder in, exactly once (M1, M-D)**: in the fresh kow audit log,
  exactly one record `type==inject_decision && decision=="allowed" &&
  secret_name=="TEST_API_KEY" && destination.host=="vault-echo.test"`, joined by
  its `request_id` to one `upstream_response` with status 200 (request_id is the
  PRIMARY join; a guest-clock timestamp bracket is a secondary sanity bound —
  L-D). A5 controls run only after this count is frozen and add ZERO allowed
  inject_decisions.
- **A4 Paperclip run completed**: terminal success carrying `<nonce>`; result
  file exists.
- **A5 Scope negative controls (C8, M3)** — each POSITIVELY records a request at
  its control mock carrying `<nonce>` and the **placeholder** fingerprint
  (absence of a request = RED):
  - A5a wrong (unbound) host — reachable because `unmatched_destination_policy:
    allow` and the control mock presents an agent-trusted cert (L-B),
  - A5b `GET` on `vault-echo.test` — no injection,
  - A5c `POST /other` (non-bound path on the bound host) — no injection.
- **A6 Clean teardown (C5, C10, L2)**: no qemu for this overlay, no hostfwd
  listener, no overlay disk, no run-scoped HOME/ssh/tmp/seed; base cache may
  persist; evidence bundle swept for the fixture → NONE. External post-check,
  not trap-reliant.
- **A7 Agent cannot read the secret at rest (H2, H-A, M-D)** — AS `agent`,
  require permission-denied by explicit path on: the `static` backend YAML, kowd
  confdir, kowd audit JSONL, kowd stdout/stderr log, upstream `received.log`,
  upstream config, seed block device, cloud-init instance-data, cloud-init logs.
  THEN a DISCOVERY sweep (not just the listed paths): enumerate every
  agent-readable file modified since the guest-boot marker, every
  `/proc/<pid>/*` and open-fd target the agent can read, and system tmp; scan
  each with **overlapping windows** (fixture may straddle a read chunk) for the
  fixture AND its base64 form → zero hits (H-A, M-E).
- **A8 Upstream TLS authenticated (L3, M-C)** — in one window: FIRST a
  correctly-upstream-CA'd request that the mock MUST record (positive control so
  the absence checks can't green vacuously), THEN a request to an upstream
  presenting a different-CA cert; require kow refuses it, the mock records no
  second request, and no allowed inject_decision for that window.

## 4b. Planted-positive sensitivity gate (H1, H-A, M-E) — BEFORE the real checks

Each detector is first proven able to FIND the fixture, using plants built from
what kow actually emits/stores (not hand-authored guesses):
- environ/maps scanners vs a root-started throwaway holding the fixture in env
  AND a heap allocation → HIT (L-A);
- the A7 discovery sweep vs a canary copy of the fixture dropped at a RANDOMLY
  chosen agent-readable path AFTER the boot marker → the sweep must find it on
  its own (proves enumeration, not just matching — H-A);
- a plant where the fixture STRADDLES the scanner's read-chunk boundary → HIT
  (proves overlapping-window reads — H-A);
- an ENCODED plant (base64 of the fixture) → HIT (M-E);
- the file scanner vs the real `static` YAML layout written by the generator;
- the A3 count assertion vs a REAL kow `inject_decision` record captured during
  this gate's own throwaway injection (not a synthetic line — M-E).
Any detector that fails its plant fails the suite before any green is trusted.

## 5. Egress hermeticity (C4, M4, M-A, M-B)

Pinned nftables output chain, exact order: (1) accept `oif lo` (loopback — all
three services are on 127.0.0.1, so this MUST precede the drop or nothing
greens); (2) accept `ct state established,related` for the sshd flow only (NOT
the slirp host alias `10.0.2.2`); (3) a NAMED-COUNTER drop for all other output.
The harness applies the ruleset, reads it back and verifies it textually, then
PROVES the drop is live: from inside the guest a NEW connection to an external
address (and to `10.0.2.2`) must fail AND the drop rule's counter must INCREMENT
(a rule that exists but never fires is a vacuous pass — M-B); the existing SSH
session must survive. Per-pid socket evidence uses `ss -tnp` (conntrack has no
pid column and omits loopback flows — M-A): assert an ESTABLISHED
`127.0.0.1`↔`127.0.0.1` socket for the kow pid to the upstream exists, and NO
non-loopback ESTABLISHED socket for the kow pid. The credentialed request runs
with this ruleset live.

## 6. Non-goals

Paperclip org-chart/governance; brokering any real credential (fixture only);
performance; the libvirt/production deployment (ADR-0006 alternative).

## 7. Invariants

Hermetic (§5); privilege-separated — tested by A7, not assumed; idempotent
(fresh overlay/ports/nonce/fixture); self-cleaning even on crash (§2); zero host
mutation outside `$SCRATCH`+repo; fixture leaves the guest only as a fingerprint
(H2, L2).

## 8. Phase order (TOCTOU discipline, M4/L1)

1 provision (egress UP, installs) → 2 generate fixture as kowd; start kowd (`static`
backend) + upstream → 3 re-arm dead-man with budget > assertion-phase timeout
(L1) → 4 sensitivity gate (§4b) → 5 apply + readback + counter-prove nftables
(§5) → 6 agent run (barrier held) → 7 sample live evidence (`ss -tnp`, environ,
maps) → 8 A1/A3/A7 under root → 9 release barrier, freeze audit count, run A5
controls + A8 → 10 assert → 11 teardown + A6.

## 9. Deliverables

- `harness/` — `up`,`provision`,`run`,`assert`,`down` (+ `down --all`
  owner-scoped). bun/TypeScript for logic; thin shell only for qemu + nftables.
- `guest/` — cloud-init seed (three users + perms, NO secret), mock upstream
  (+ wrong-CA variant for A8), agent script (barrier in `finally`), kow bindings
  + in-guest `static`-backend fixture generator, kowd log redirection, Paperclip
  install/config, nftables ruleset.
- `tests/` — A0-A8 + §4b gate, machine-readable PASS/FAIL, fixture-free evidence
  bundle (L2).
- `docs/RESULTS.md` — fingerprints-only evidence summary after a green run.

## 10. kow ground-truth the spec binds to (verified against source)

`kow run` sets env + CA vars and execs; starts no proxy; sandboxes nothing;
exits if it cannot read the CA. Audit records: `type`,`request_id`,`reason`,
`destination{host,port,path_prefix}`,**`secret_name`**,`decision` (allowed|denied);
NO headers, NO nonce. Backends: `aws|bws|gsm|keychain|static`; `static` is the
only plaintext-at-rest store (YAML `secrets:`, refuses world-readable, in-memory
cache). kow does not follow redirects. Default `tls_termination: bound` → opaque
passthrough for unmatched hosts (hence A5a's trusted control cert +
`unmatched_destination_policy: allow`). Upstream cert verification is a mitmdump
argv option, not automatic (A8 proves it is actually set).
